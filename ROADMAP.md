# Roadmap

1. Add a reviewable CSV column-confirmation screen and persisted real-flight imports.
2. Expand tolerant OpenRocket parsing against a representative set of student artifacts.
3. Add a WebSocket telemetry adapter and an Open MCT-compatible provider.
4. Add authenticated multi-user projects, PostgreSQL, and encrypted key management for deployment.
5. Integrate external flight-software test runners through explicit adapters rather than bundling them.

Each future item must preserve the product boundary: the platform connects and validates engineering workflows; it does not replace specialist tools.
